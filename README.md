# ChatBot
The Animal Disease Helper is an intelligent Streamlit-powered chatbot designed to provide comprehensive veterinary health information. Leveraging advanced natural language processing and machine learning techniques, this application allows users to quickly explore animal diseases by searching symptoms, disease names, or specific health queries. 

run a demo at:
